# MASDiff框架解决的问题详细描述

## 核心问题：交通状态优化

MASDiff框架解决的是大规模交通网络中通过进化算法让车辆选择最优路径，使实际交通状态接近期望目标。

## 预测路况部分（Tau）

### Tau的定义和作用

**Tau（τ）**：交通状态张量，表示当前的路况信息

### 数据结构

**形状**：`[num_car, num_road, 2]`

**维度含义**：
- `num_car`：车辆数量（如2336辆）
- `num_road`：路段数量（如114条路段）
- `2`：每个路段的两个特征
  - 特征0：距离到目的地的距离
  - 特征1：排队长度（拥堵程度）

### 具体含义

```
tau[car_id, road_id, 0] = 车辆car_id在路段road_id到目的地的距离
tau[car_id, road_id, 1] = 车辆car_id在路段road_id的队列长度
```

### Tau的作用机制

#### 1. 条件生成奖励

扩散模型根据tau条件生成对应的rewards

**公式**：
```
rewards = diffusion_model.generate_rewards_given_tau(tau)
```

不同路况（tau）会产生不同的路径偏好（rewards）

#### 2. 反映实时交通状况

- tau值高表示拥堵严重，需要避开
- tau值低表示路况良好，可以选择

**注意**：tau值只是反应路况对于仿真的需求，扩散模型根据tau条件生成对应的rewards，从而间接引导路径的选择

rewards反映了对各路段的偏好程度

## 适应度评估部分（Rho）

### Rho的定义

**Rho（ρ）**：适应度指标，衡量个体（路径选择方案）的优劣

### 核心概念

- **Q**：目标交通状态（期望的交通状况）
- **simulation_data**：实际仿真数据（当前路径选择产生的交通状况）
- **Rho**：反应的就是目标期望的交通状态和仿真的数据的符合情况
